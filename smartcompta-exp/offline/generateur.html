Générateur de codes SmartCompta Exp

Document confidentiel : ne le transmettez à personne. Il contient la clé qui produit les codes d'activation.

1. Activer un ordinateur précis

Au premier démarrage, SmartCompta Exp affiche « Code de cet ordinateur » (8 caractères). Saisissez-le ici : le code d'activation obtenu ne fonctionne que sur cet ordinateur.

À saisir dans l'écran « Code d'accès » de cet ordinateur.

2. Codes d'accès prêts à l'emploi

Chaque code active n'importe quel ordinateur. Remettez un code différent à chaque client et notez-le dans votre registre : le numéro de licence apparaît dans l'écran Dossier du logiciel.
